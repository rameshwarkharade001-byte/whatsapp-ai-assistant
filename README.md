# AI WhatsApp Assistant Bot

A lightweight automated WhatsApp assistant built with Node.js, Baileys, and Groq Cloud LLM.

### Features
- Natural Marathlish conversation replies
- Auto-pause when user is active
- Spam and business bot filtering
- Runs 24/7 in background via PM2

### Setup
1. Clone repo: git clone <repo-url>
2. Install packages: npm install
3. Add .env file with GROQ_API_KEY=your_key
4. Run: node server.js
